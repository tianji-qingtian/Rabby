# M0：骨架与本地终端垂直切片（2026-11-05）

## 状态：完成

- workspace：15 个 crate（core/config/secrets/import-tabby/terminal/pty/ssh/session/platform/terminal-view/ui/ext-api/ext-host/app/test-support），prototype 排除在 workspace 外。
- 工具链：rust-toolchain nightly + gpui-kit 0.9.0 + wezterm-term git pin + portable-pty 0.9；vendor pathfinder_simd 补丁。
- 构建/测试：cargo build、cargo test --workspace、cargo fmt --check、cargo clippy --workspace --all-targets -- -D warnings 均通过。
- 运行：GPUI Kit 窗口 + macOS shell catalog（dscl）+ portable-pty + wezterm TerminalCore + TerminalElement/TerminalPane；可显示 shell 提示符，键盘输入/resize 已接。

## 已验证

- 本地 PTY spawn 与输出到 TerminalCore；screen 行渲染。
- 窗口 resize 会同步 TerminalCore + PTY。
- 键盘字符/Enter/Backspace/Tab/Esc/方向键/Home/End/PageUp/PageDown/Delete/Insert 经 wezterm key_down 编码。
- macOS 默认 shell 探测（dscl UserShell，回退 $SHELL；/etc/shells 列表）。

## 复现

    cargo build
    cargo test --workspace
    cargo run -p rabby-app

本地构建需要 nightly 工具链和 CARGO_HOME；CI 使用 dtolnay/rust-toolchain@nightly。
