# M1：多标签 + PaneTree 嵌套分屏（2026-11-05）

## 状态：完成（macOS dogfood 通过）

- Workspace：多标签 Tab strip、PaneTree 递归分屏、每标签独立 active pane。
- 分屏：Cmd+D 左右分；Cmd+Shift+D 上下分；可继续对当前 pane 分屏，形成四向嵌套。
- 标签：新建（Cmd+T / +）、关闭（Cmd+W / ×）、激活、重命名（Cmd+R / ✎ / 双击）、拖动重排（GPUI on_drag/on_drop）、最大化（Cmd+Shift+M / ⛶）。
- 点击任意 pane 会聚焦并把该 pane 设为当前 active pane（事件订阅）。
- 拖拽：标签拖动到另一标签前插入；跨窗口/边缘分屏不在 M1。

## 快捷键

- Cmd+T 新建标签
- Cmd+W 关闭当前标签
- Cmd+D 左右分屏；Cmd+Shift+D 上下分屏
- Cmd+R 重命名当前标签
- Cmd+Shift+M 最大化/还原当前 pane

## 已知限制

- 分屏比例固定 0.5，分隔条还不能拖动。
- 没有关闭单个 pane（只关闭整个标签）。
- 标签拖动重排的鼠标路径未自动化测试（代码已接 on_drag/on_drop）。
- macOS 中文输入法下，重命名输入需要先把候选词上屏再按一次回车；正常英文输入法一次回车即可。
