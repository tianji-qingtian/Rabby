# 08: 平台、分发与品牌

Type: grilling

Blocked by: 02, 07
Status: resolved
## Question

目标：锁定 Rabby 的交付形态与产品外壳。

要讨论：
- 平台顺序：桌面三平台首发顺序；Web 是否/何时；移动是否做（NSH 的 iOS/Android 是否值得）；
- 安装与更新：dmg/msi/AppImage/deb/rpm、自动更新通道、签名/公证、便携模式；
- 品牌：Rabby 是否正式名、与 Tabby 的关系/致谢、许可证（MIT 衍生）；
- 遥测/崩溃上报：默认开/关、隐私边界；
- 发布节奏（nightly/beta/stable）与回滚。

产出：平台/分发/品牌决策，写回 Answer。

## Answer

平台：macOS 先行 → Windows → Linux；GitHub Releases 直发；macOS dmg / Windows msi+便携 zip / Linux AppImage+deb；开发期未签名，macOS 公开 beta 前买 Apple 账号（99 美元/年）并公证，Windows 证书 v1.x；Rabby 仅内部代号、公开名前做商标检索；MIT/Apache-2.0 双许可 + NOTICE；nightly+stable，v1 手动更新、v1.x 自动更新；Web/移动 v1.x 后再评估。详见 .scratch/rust-rewrite/specs/platform-distribution.md
