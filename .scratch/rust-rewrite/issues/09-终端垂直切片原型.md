# 09: 终端垂直切片原型

Type: prototype

Blocked by: 02, 03
Status: resolved
## Question

目标：用最便宜的方式验证“GPUI(KIT) + Rust 终端内核 + PTY”这条主路径，并给 UI/内核决策提供可反应的东西。

做：
- 一个可运行的桌面窗口：标签/分屏壳（可用 GPUI Kit DockArea/TabGroup 或最小自绘）+ 一个终端网格；
- 接本地 PTY（macOS/Linux 至少一个，Windows 如可行）；
- 验证：启动到首帧、键盘输入延迟、1MB/s 输出吞吐、resize、滚动、选择/复制、CJK 宽字符与 IME 候选窗、ligatures、字体回退；
- 对比 Tabby 同场景的主观/客观数据；
- 记录哪些 GPUI Kit 组件直接可用、哪些要自研、哪些 NSH 可补；
- 原型代码放 `prototype/` 或独立临时目录，不进入产品架构。

产出：可运行原型 + 一页测量结果 + 风险清单，链接到本票。

## Answer

原型结论：GPUI Kit 0.9 + wezterm-term + portable-pty 在 macOS arm64 跑通；headless release 50.8 MB/s、25k scrollback RSS 36.5MB；GPUI release 36 行 CJK/emoji 动画约 60fps，32MB feed 33.4 MB/s / 约 30fps，app RSS 约 142MB；PTY resize/SIGWINCH 通过。构建需 nightly 1.101 + pathfinder_simd 补丁；Windows/IME/vttest 未测；feed 必须按字节预算，不能按 chunk 数。详见 specs/09-prototype-report.md 与 prototype/ 截图。
